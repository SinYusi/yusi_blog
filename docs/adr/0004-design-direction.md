# 0004. 디자인 방향: 터미널 블루

- 상태: 승인
- 날짜: 2026-09-28

## 배경

디자인 토큰과 컴포넌트를 구현하기 전에 블로그의 시각적 방향을 정해야 한다. 이 블로그는 개발 과정의 문제 해결과 측정 결과를 기록하는 곳이라, 로그, diff, 코드 같은 기술 콘텐츠를 자연스럽게 담을 수 있어야 한다.

## 선택지

같은 콘텐츠로 홈 화면 시안 세 가지를 만들어 비교했다.

1. **에디토리얼:** 아이보리 바탕, 명조 제목. 긴 글을 읽기 편하지만 코드·로그 블록이 이질적으로 보인다.
2. **터미널:** 어두운 바탕, 모노스페이스 메타 정보. 로그와 diff가 화면 스타일과 자연스럽게 이어진다.
3. **스위스 그리드:** 큰 글자와 번호, 굵은 선. 인상은 강하지만 글이 늘어날수록 목록 화면이 단조로워진다.

터미널 안에서는 강조색을 두 가지로 비교했다.

- **그린(라임):** 터미널 느낌이 강하지만 오래 읽기에는 자극적이다.
- **블루(하늘색):** 차분하고, 날짜에 쓰는 앰버색과 보색 관계라 정보 구분이 쉽다.

## 결정

터미널 방향에 블루 강조색을 사용한다. 다크 테마를 기본으로 하고 라이트 테마를 함께 제공한다.

## 결과

- 로그, diff, 코드 블록을 본문 요소로 적극 활용한다.
- 날짜·태그·내비게이션 같은 메타 정보는 JetBrains Mono, 본문과 제목은 IBM Plex Sans KR을 쓴다.
- 라이트 테마는 같은 토큰 이름에 다른 값을 넣어 만든다. 강조색은 흰 바탕에서 대비를 맞추기 위해 더 짙은 파란색(`#1b64c8`)을 쓴다.
- 보류한 시안은 디자인 캔버스의 "탐색 기록" 페이지에 남겨 둔다.
- 세부 값은 [DESIGN.md](../DESIGN.md)에 정리한다.
