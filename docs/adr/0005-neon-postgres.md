# 0005. DB 호스팅: Neon

- 상태: 승인
- 날짜: 2026-09-28

## 배경

[ADR-0002](0002-self-hosted-cms.md)에서 자체 CMS와 PostgreSQL을 쓰기로 했다. 무료 범위 안에서 운영할 서버리스 Postgres 호스팅을 정해야 한다. 개인 블로그라 초기에는 방문과 글 작성이 뜸하다.

## 선택지

|                  | Neon                                          | Supabase                                                         |
| ---------------- | --------------------------------------------- | ---------------------------------------------------------------- |
| 무료 DB 용량     | 프로젝트당 0.5GB                              | 500MB                                                            |
| 사용하지 않을 때 | 5분 뒤 자동으로 멈추고, 요청이 오면 다시 켜짐 | 7일간 사용량이 적으면 프로젝트 일시 정지, 대시보드에서 직접 복구 |
| 브랜치           | 프로젝트당 10개 (미리보기 배포별 DB 분리)     | 무료 요금제에서 사실상 사용 불가                                 |
| 함께 주는 기능   | Postgres만                                    | 인증, 파일 저장소, 실시간 기능                                   |

(2026-09 기준 공개 요금제 정보)

## 결정

Neon을 사용하고, Drizzle ORM과 Neon HTTP 드라이버로 접근한다.

- **일시 정지가 없다.** 방문이 뜸한 초기에도 운영 DB가 끊기지 않는다. 멈춰 있다가 켜지는 첫 요청은 느리지만, 공개 페이지는 정적으로 생성하므로 방문자에게 미치는 영향이 작다.
- **미리보기별 DB 브랜치.** 스키마를 바꾸는 PR을 운영 데이터와 분리해 미리보기에서 확인할 수 있다.
- **스펙과 기능이 겹치지 않는다.** 인증(Auth.js)과 이미지 저장소는 따로 정했으므로 Supabase의 묶음 기능은 대부분 쓰지 않는다.

## 결과

- 연결은 Vercel의 Neon 연동으로 관리한다. 배포 환경의 `DATABASE_URL`, `DATABASE_URL_UNPOOLED`는 연동이 설정한다.
- 앱 쿼리는 HTTP 드라이버(`drizzle-orm/neon-http`)를 쓴다. 여러 쿼리를 한 트랜잭션으로 묶어야 하는 CMS 쓰기 작업은 2단계에서 WebSocket 드라이버를 추가한다.
- 마이그레이션(drizzle-kit)은 커넥션 풀러를 거치지 않는 `DATABASE_URL_UNPOOLED`를 우선 사용한다.
- DB 연결 코드는 `server-only`로 표시해 클라이언트 번들에 포함되지 않게 한다.
- 이미지 저장소는 2단계 전에 따로 정한다.
- 무료 한도(컴퓨트 월 100 CU-시간, 저장 0.5GB)를 넘으면 컴퓨트가 다음 달까지 멈추므로, 사용량을 주기적으로 확인한다.
