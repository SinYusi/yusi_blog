# 디자인

> 방향: **터미널 블루** · 다크 기본 + 라이트 · 결정 배경은 [ADR-0004](adr/0004-design-direction.md)

화면 시안은 디자인 캔버스에서 관리합니다. (캔버스는 비공개라 저장소 소유자만 열 수 있습니다.)

- 캔버스: https://claude.ai/artifact/E7tbLABWQaxwLedaJq8jBY

## 1. 색

토큰 이름은 CSS 변수(`--<이름>`)와 Tailwind 유틸리티(`bg-<이름>`, `text-<이름>`, `border-<이름>`)에 그대로 씁니다. 값의 기준은 `src/app/globals.css`이고, Tailwind 기본 색은 비활성화해 이 토큰만 쓸 수 있습니다.

| 토큰            | 다크 (기본) | 라이트    | 용도                      |
| --------------- | ----------- | --------- | ------------------------- |
| `bg`            | `#0e1320`   | `#f6f8fc` | 페이지 바탕               |
| `surface`       | `#151c2e`   | `#ffffff` | 카드, 입력칸, 사이드 패널 |
| `code`          | `#0a0e18`   | `#eef2f8` | 코드 블록, 로그           |
| `border`        | `#263049`   | `#dbe1ec` | 구분선, 기본 테두리       |
| `border-strong` | `#36415c`   | `#c5cedd` | 강조 테두리, 모달         |
| `fg`            | `#e3e8f2`   | `#141a2a` | 기본 글자                 |
| `fg-secondary`  | `#b3bdd3`   | `#3a4459` | 보조 본문, 카드 요약      |
| `fg-article`    | `#cdd5e5`   | `#2a3246` | 글 본문                   |
| `muted`         | `#8f9bb5`   | `#55617a` | 날짜 외 메타, 비활성 링크 |
| `accent`        | `#6cb6ff`   | `#1b64c8` | 링크, 강조, 주요 버튼     |
| `accent-hover`  | `#a3d2ff`   | `#0f5fc4` | 링크·버튼 호버, 포커스 링 |
| `date`          | `#f2b134`   | `#9a6200` | 날짜, 주의                |
| `danger`        | `#f28b82`   | `#c0392b` | 에러                      |
| `success`       | `#7fd8a4`   | `#1e7a4c` | 성공, 발행 상태           |

- 주요 버튼은 `accent` 바탕에 `bg` 글자를 씁니다 (다크 8.6:1).
- 실제로 함께 쓰는 글자·배경 조합은 모두 WCAG AA(4.5:1) 이상이며, `pnpm check:contrast`가 CI에서 검사합니다. 가장 낮은 조합은 `muted` on `border` (다크 4.70:1, 라이트 4.74:1)입니다.

## 2. 글꼴

| 역할                                         | 글꼴             | 굵기               |
| -------------------------------------------- | ---------------- | ------------------ |
| sans (본문, 제목)                            | IBM Plex Sans KR | 400, 500, 600, 700 |
| mono (코드, 날짜·태그 같은 메타, 내비게이션) | JetBrains Mono   | 400, 500, 700      |

| 단계      | 크기 / 굵기   | 용도                |
| --------- | ------------- | ------------------- |
| `display` | 56 / 700      | 홈 소개 문구        |
| `h1`      | 44 / 700      | 페이지·글 제목      |
| `h2`      | 28 / 700      | 본문 소제목         |
| `h3`      | 21 / 600      | 목록의 글 제목      |
| `body-lg` | 18 / 400      | 글 본문 (모바일 16) |
| `body`    | 15 / 400      | 요약, 설명          |
| `meta`    | 13 / 400 mono | 날짜, 태그          |
| `caption` | 12 / 400      | 보조 라벨           |

- 한글은 단어 단위로 줄바꿈합니다(`word-break: keep-all`). 긴 영문·URL은 넘치지 않도록 끊습니다(`overflow-wrap: break-word`).
- 한글 폰트는 preload하지 않습니다. 수백 개의 unicode-range 조각 중 페이지에 쓰인 글자의 조각만 받게 하기 위해서입니다 (성과 기록: 폰트 전송량 −87%).

글자 크기는 `text-display`, `text-h1` … `text-caption` 유틸리티로 쓰며, 줄 간격·자간·굵기가 함께 적용됩니다. display, h1, h2, h3, body-lg는 `clamp()`로 화면 너비에 따라 연속으로 바뀝니다.

## 3. 간격 · 모서리

- 간격: 4px 단위 — `4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96`
- 모서리: `sm 4` · `md 6` · `lg 8` · `xl 10` · `2xl 12` · `full`

## 4. 반응형

| 구간     | 너비       | 레이아웃                                                                  |
| -------- | ---------- | ------------------------------------------------------------------------- |
| 모바일   | ~767px     | 한 단, 햄버거 메뉴, 좌우 여백 20, 사이드바 숨김, 목차 접이식              |
| 태블릿   | 768~1023px | 한 단, 메뉴 펼침(검색은 아이콘), 좌우 여백 40, 목차 접이식                |
| 데스크톱 | 1024px~    | 12칸 그리드에서 본문 8칸 + 사이드바 3칸, 좌우 여백 96, 목차 고정 사이드바 |

- 본문 최대 너비: 680px (`max-w-article`, 한글 한 줄 약 40자)
- 콘텐츠 최대 너비: 1088px (`max-w-content`)
- 너비 구간 접두사는 `md:`(768), `lg:`(1024) 두 개만 씁니다.
- 제목 크기는 화면 너비에 따라 연속으로 조정합니다 (h1: 26 → 34 → 44).
- 코드 블록은 줄바꿈하지 않고 가로로 스크롤합니다.
- 모든 버튼과 링크의 터치 영역은 최소 44×44px입니다.
- 이미지는 비율을 고정해 레이아웃 이동(CLS)을 막습니다.

## 5. 테마 전환

- `<html data-theme="dark|light">`로 전환하며, 기본값은 다크입니다.
- 선택한 테마는 `localStorage`의 `theme` 키에 저장합니다.
- `<head>`의 인라인 스크립트가 HTML 파싱 중에 저장된 테마를 적용하므로, 첫 화면부터 올바른 테마로 그려집니다 (깜빡임 없음). 페이지는 정적 렌더링을 유지합니다.
- 요소 단위로 `data-theme`을 지정하면 그 안만 다른 테마로 보여 줄 수 있습니다 (`/design` 페이지의 색 견본).
- 토큰 확인 페이지: `/design`
