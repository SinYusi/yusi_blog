# 디자인

> 방향: **터미널 블루** · 다크 기본 + 라이트 · 결정 배경은 [ADR-0004](adr/0004-design-direction.md)

화면 시안은 디자인 캔버스에서 관리합니다. (캔버스는 비공개라 저장소 소유자만 열 수 있습니다.)

- 캔버스: https://claude.ai/artifact/E7tbLABWQaxwLedaJq8jBY

## 1. 색

토큰 이름은 CSS 변수(`--color-<이름>`)와 Tailwind 테마에 그대로 사용합니다.

| 토큰             | 다크 (기본) | 라이트    | 용도                      |
| ---------------- | ----------- | --------- | ------------------------- |
| `bg`             | `#0e1320`   | `#f6f8fc` | 페이지 바탕               |
| `surface`        | `#151c2e`   | `#ffffff` | 카드, 입력칸, 사이드 패널 |
| `code`           | `#0a0e18`   | `#eef2f8` | 코드 블록, 로그           |
| `border`         | `#263049`   | `#dbe1ec` | 구분선, 기본 테두리       |
| `border-strong`  | `#36415c`   | `#c5cedd` | 강조 테두리, 모달         |
| `text`           | `#e3e8f2`   | `#141a2a` | 기본 글자                 |
| `text-secondary` | `#b3bdd3`   | `#3a4459` | 보조 본문, 카드 요약      |
| `text-article`   | `#cdd5e5`   | `#2a3246` | 글 본문                   |
| `muted`          | `#8f9bb5`   | `#55617a` | 날짜 외 메타, 비활성 링크 |
| `accent`         | `#6cb6ff`   | `#1b64c8` | 링크, 강조, 주요 버튼     |
| `accent-hover`   | `#a3d2ff`   | `#0f5fc4` | 링크·버튼 호버, 포커스 링 |
| `date`           | `#f2b134`   | `#9a6200` | 날짜, 주의                |
| `danger`         | `#f28b82`   | `#c0392b` | 에러                      |
| `success`        | `#7fd8a4`   | `#1e7a4c` | 성공, 발행 상태           |

- 주요 버튼은 `accent` 바탕에 `bg` 글자를 씁니다 (다크 8.6:1).
- 모든 글자·배경 조합은 WCAG AA(4.5:1) 이상입니다. 가장 낮은 조합은 다크 `muted` on `border` 4.7:1, 라이트 `accent` on `code` 5.05:1입니다.

## 3. 간격 · 모서리

- 간격: 4px 단위 — `4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96`
- 모서리: `sm 4` · `md 6` · `lg 8` · `xl 10` · `2xl 12` · `full`

## 4. 반응형

| 구간     | 너비       | 레이아웃                                                                  |
| -------- | ---------- | ------------------------------------------------------------------------- |
| 모바일   | ~767px     | 한 단, 햄버거 메뉴, 좌우 여백 20, 사이드바 숨김, 목차 접이식              |
| 태블릿   | 768~1023px | 한 단, 메뉴 펼침(검색은 아이콘), 좌우 여백 40, 목차 접이식                |
| 데스크톱 | 1024px~    | 12칸 그리드에서 본문 8칸 + 사이드바 3칸, 좌우 여백 96, 목차 고정 사이드바 |

- 본문 최대 너비: 680px (한글 한 줄 약 40자)
- 콘텐츠 최대 너비: 1088px
- 제목 크기는 화면 너비에 따라 연속으로 조정합니다 (h1: 26 → 34 → 44).
- 코드 블록은 줄바꿈하지 않고 가로로 스크롤합니다.
- 모든 버튼과 링크의 터치 영역은 최소 44×44px입니다.
- 이미지는 비율을 고정해 레이아웃 이동(CLS)을 막습니다.

## 5. 화면 목록

| 영역   | 화면                                                                         | 시안                                   |
| ------ | ---------------------------------------------------------------------------- | -------------------------------------- |
| 공개   | 홈                                                                           | 데스크톱(다크, 라이트), 태블릿, 모바일 |
| 공개   | 글 상세                                                                      | 데스크톱, 태블릿, 모바일               |
| 공개   | 글 목록 (태그 필터, 정렬, 페이지네이션)                                      | 데스크톱                               |
| 공개   | 태그 목록, 태그별 글                                                         | 데스크톱                               |
| 공개   | 시리즈 목록, 시리즈 상세                                                     | 데스크톱                               |
| 공개   | 검색 (⌘K 창)                                                                 | 데스크톱, 모바일(전체 화면)            |
| 공개   | 소개, 404                                                                    | 데스크톱                               |
| 공개   | 모바일 메뉴                                                                  | 모바일                                 |
| 관리자 | 로그인, 글 목록(상태 필터), 에디터(슬래시 커맨드, 자동 저장 상태, 발행 설정) | 데스크톱 · 구조 수준                   |

- 라이트 테마는 토큰 교체로 만들며, 홈 라이트 시안으로 대표 확인만 합니다.
- 관리자 화면의 세부 동작은 Tiptap 구현 단계에서 확정합니다.
